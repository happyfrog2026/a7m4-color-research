Custom1 M9 resource C/D profiles

The forward profile adapts the existing MIT resource-forward worker
(source SHA256 a4b1fb058a58b0c90c93aa6fbf7f716859ae9f7dfba4fc5738d40f415a7ba642).
The EOF profile adapts the retained R067 tail remap/truncate mechanism and the
independent original-EOF profile (source SHA256
eec73b909f85e01a5b35f643e09637f8497511765fc897ecfddb0b1c42757a68).
Their original sources and licenses remain unchanged in the release source
closure. New finite C/D admission and dynamic reference bounds use the same
MIT license as those native helpers.

The Python adapters reuse the existing looks string-index and C2 image-bank
algorithms and the native-icons codec. Existing C2 notices, Sony internal-only
template rights and the M9 recipe license/attribution still apply. This folder
contains no bitmap template, firmware, native resource, backup, body binding,
device inode/address, calibration or private journal. Generated manifests and
original-C capsules are private local artifacts and must not be distributed.
