## Repository contents

This repository contains documentation, CLI convenience entry points and source excerpts. The excerpts exclude complete App runtimes, native asset libraries, recorded media, body backups, calibration, user photos, body bindings and private job records. User-selected assets retain their own rights.

Python, NumPy, Pillow, USB dependencies and compiler environments are provided by the matching App or the user's environment. These complete runtimes are not redistributed here. Consult the corresponding actual distributions for their original notices.
